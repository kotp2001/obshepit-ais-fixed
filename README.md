# АИС «Общепит»

Автоматизированная информационная система для предприятий общественного питания
(кафе, ресторан, столовая): меню, столы, заказы, оплата, кухня, отчёты,
резервное копирование и журналы. Дипломный проект на Django.

## Роли пользователей

| Роль          | Логин   | Пароль     | Интерфейс             |
|---------------|---------|------------|-----------------------|
| Администратор | admin   | admin123   | Панель администратора |
| Официант      | waiter  | waiter123  | Зал, заказы, оплата   |
| Повар         | chef    | chef123    | Кухня, статусы блюд   |

## Запуск локально (SQLite)

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Создать структуру базы данных
python manage.py migrate

# 3. Создать пользователей с ролями (admin / waiter / chef)
python manage.py create_users

# 4. (необязательно) Заполнить демонстрационные данные меню/столов
python create_migrations.py

# 5. Запустить сервер разработки
python manage.py runserver
```

После запуска открыть http://127.0.0.1:8000/ и войти под одной из учётных записей.
Админка Django доступна по адресу http://127.0.0.1:8000/admin/.

## База данных

* Локально по умолчанию используется SQLite (файл `db.sqlite3` создаётся автоматически).
* В продакшене (Render) используется PostgreSQL — подключается автоматически,
  если задана переменная окружения `DATABASE_URL`.

## Резервное копирование

Раздел «Резервное копирование» (`/backup/`) создаёт снимки данных в формате JSON
и хранит их прямо в базе данных, поэтому копии не теряются при перезапуске сервера.
Копию можно скачать, загрузить из файла и восстановить.

## Структура проекта

```
restaurant_project/   — настройки проекта (settings, urls, wsgi)
restaurant/           — приложение: модели, представления, админка, API, экспорт Excel
templates/            — HTML-шаблоны (страницы сотрудников и кастомная админка)
static/               — статические файлы (CSS, изображения)
```

Все основные файлы снабжены поясняющими комментариями.
